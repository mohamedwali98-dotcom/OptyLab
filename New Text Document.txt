1. User uploads image
       ↓  POST /upload  → saved to backend/uploads/
2. User clicks "Run Classification"
       ↓  POST /classify
           ├─ If models trained → SVM + CNN + ViT predict (real ML)
           └─ If not trained   → image-derived fallback (gradient, contrast, entropy)
       ↓  majority vote → final label
       ↓  written to results.json
3. User views results
       ↓  GET /results  → reads results.json
       ↓  GET /thumbnail/<file> → serves the actual image
4. User corrects a wrong label
       ↓  POST /correct-prediction
           ├─ copies image to DB/Good or DB/Damaged
           └─ updates results.json (confidence = 1.0, corrected = true)
5. User retrains the model
       ↓  POST /train
           ├─ trains SVM on HOG features
           ├─ fine-tunes ResNet18 (CNN)
           └─ fine-tunes ViT-B/16
       ↓  saves .pkl/.pth + stats.json
       ↓  next classification uses real model probabilities
